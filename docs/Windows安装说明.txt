拾光 · 失物招领系统 1.1.1（Windows x64 离线安装版）

适用于 Windows 10 1809 及以上的 64 位 Windows。
安装包内含 Java 21、Python 3.13、CPU 版 AI 依赖和中文语义模型。
安装和使用不需要再下载 Java、Python、Maven 或 AI 模型。

使用方法
1. 安装完成后，双击桌面“拾光失物招领系统”。
2. 等待启动完成，浏览器自动打开本机网站。
3. 普通用户点击“登录 / 注册”；管理员首次启动后自动生成随机密码。
4. 在开始菜单“拾光失物招领系统”中选择“查看管理员账号”。
5. 使用完毕可在开始菜单选择“停止拾光系统”。关闭浏览器不会停止后台服务。

数据与升级
- 本安装包不包含原开发电脑的账号、物品、消息、上传图片和测试数据。
- 数据保存在当前 Windows 用户的 %LOCALAPPDATA%\ShiguangLostFound。
- “打开数据目录”可查看 data（数据库与附件）和 runtime（日志）。
- 备份前先停止系统，再复制整个 data 目录。
- 升级和卸载默认保留数据。重新安装后会继续使用已有数据。
- 首次安装未生成管理员凭据时，请先启动系统。

访问范围
网站和 AI 服务只监听本机，默认端口分别为 8080 和 8765。
不同电脑安装后各自拥有独立的数据，不会自动共享同一个失物招领站点。
如提示端口被占用，请关闭占用端口的程序后重试。

测试账号与演示数据
- 安装版与 D:\Lost_Found_System 开发版使用不同数据库，原测试账号不会自动带入。
- 先启动一次系统，再从开始菜单选择“初始化测试数据”，或双击安装文件夹内同名入口。
- 初始化会备份数据库，追加 5 个虚构账号、16 条测试物品和 7 条申请，保留现有管理员和业务。
- 普通测试账号 demo_finder、demo_owner、demo_claimant、demo_delete，初始密码 Demo123456!。
- demo_banned 初始被封禁，无法登录属于预期；修改密码或注销账号后，重复初始化不会恢复。
- 安装版账号与物品编号请查看 %LOCALAPPDATA%\ShiguangLostFound\data\测试账号与数据.md。
- 管理员密码仍以安装版“查看管理员账号”为准，和开发版管理员密码不同。
